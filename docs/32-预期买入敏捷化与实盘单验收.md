# 32-预期买入敏捷化与实盘单验收（v0.13）

> 版本：buysell_core v0.13　目标：让「超预期确认后的触发买点」从 1 分钟级别降到 ~3 秒（tick_data 事件触发），并把「预期买入」作为首个放开真实下单的路径做实盘单测试。配套 docs/25（三态流水线）、docs/30（tick 首笔）、docs/24（上线清单）。

## 1. 为什么原先不够敏捷
- 预期买入只在 1m handle_data 里评估；确认用按日缓存的竞价涨幅(_auction_change)，等于一旦首次求值，当日就不再更新 → 盘中「超预期/快速上攻」那段确认**永远采不到**。
- 结果：超预期确认到买点之间最多差 ~60s，且快速上攻类机会会被错过。

## 2. v0.13 设计（采集即决策，仅预期买入路径）
- tick_data（仅交易，9:30-14:59 每 3s）帧末统一调 _try_expected_buys()；handle_data(1m) 兜底共用同一入口 → 同一判定+去重，杜绝双触发。
- 实时确认 _exp_rt_status(code) 返回 (state, reason)：
  | 场景 | 判定 | 动作 |
  | --- | --- | --- |
  | 超预期-竞价已达标 | _confirm_expected == CX | 立买 |
  | 超预期-盘中快速上攻 | _two_1m_break(sec) 且竞价是 PX/CX 语境 | 立买 |
  | 超预期-走弱 | _below_vwap(sec) | 放弃(CS) |
  | 一字板 | _exp_one_word L2 封单(超预期/衰竭) | 买/放弃 |
  | expected_status=miss | —— | 放弃 |
  | meet/未标注 | _eval_intraday 标准三态 | 按需 |
- 一次触发去重 g.exp_fired：买/放弃都记，持久化进 buysell_core_state.pkl（跨重启不双买，日切清空）。防止 3s 帧内重复下单与重启后重放。

## 3. 实盘单门控（核心：只对预期买入放真实单）
- EXPECT_ORDER（默认 False）：True 时预期买入发真实 order()；其余买入通道仍受 DO_ORDER 门控 → 可「模拟盘小额真实下单」专测超预期买点敏捷度与成交流，不动其它逻辑。
- exp_order_pct（默认 0.3）：预期买入单笔仓位比例，实盘测试可调小到 0.01。
- 发单打 [exp-order]（带 True/False 标注）；放弃打 [exp] ... miss -> skip。

## 2026-10-18 修正：预期买入两阶段（v0.14，用户确认逻辑）
- 原 v0.13 把「竞价超预期」直接判 CX 买入。按用户申明改为两阶段：
  1. 竞价终态初步确认竞价超预期（真实竞价>=expected_auction_change_pct）-> **观察**（PM observe，不买）；
  2. 分时确认超预期（两分钟上攻 _two_1m_break 且未破 VWAP）-> **CX -> 执行买入**；
  3. 分时转弱（破 VWAP）-> **放弃**。
- 关键修复：expected_status 前缀 pending_ 使 startswith("exceed") 失效，改按 "exceed"/"miss" 包含匹配（3 处）。否则 pending_exceed 走不到超预期分支。
- 观察可观测：首次进入观察打 [exp] ... observe ... -> 观察中(等分时确认)；后续分时确认才 [exp-order]。
- 自测 selftest_exp_rt.py 9/9；PT3.7 编译通过。

## 2026-10-18 分时确认超预期双触发（v0.14 细化）
- 分时确认超预期 = 两分钟上攻(_two_1m_break 站上 open*(1+fast_up_ratio)) **或** 一分钟冲涨停(_limit_up_within_1m：触及涨停价且 09:30-09:32)，且未破 VWAP -> CX 买入。
- 竞价超预期仅观察（PM observe）；破 VWAP -> 放弃。

## 2026-10-18 买入定价与限价（打板 vs 追高）
- 修复：order() 第三参是 limit_price，勿把 buy/sell 方向串当价格传入。两处下单统一 order(sec,qty,limit_price=limit)。
- 决策：一分钟冲涨停 / 一字板 -> 打板（涨停价排队）；两分钟上攻未触板 -> 追高（现价*(1+0.8%) 封顶涨停价）；ma5 回踩 -> 现价限价。现金仓位按 limit 最坏价计 qty。
- 分时确认超预期是买入价格的关键分界：触板即打板，未触板限价上浮防过度追高。
- 一字板超预期门控：仅封单超预期(CX)买入，封单符合(CM)等待（避免未超预期就追）。
