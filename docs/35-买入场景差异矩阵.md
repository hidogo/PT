# 35-买入场景差异矩阵（AXquant vs PT 托管）v0.15 审计

> 结论：PT 侧实际生效 4 条买入入口（预期买入 + ma5 低吸 + 核心票 + 首板打板）；AXquant 权威买入场景 8+2 个。
> 本轮已对齐 ma_pullback 与预期买入（含打板/追高/一字封死不排队/弹性10%上限定价）；
> v0.18 已落地 **try_core_buy（核心票买入）** 与 **first_board_buy（首板确认→打板）**；
> v0.19 已落地 **elastic_arb（Phase 1）**；仍缺：**加仓(含对倒加仓)、高开追涨、对倒机会、共振、分笔买入**。

## 1. AXquant 权威买入场景（btree/builder.py trading_buy_scenarios 选择顺序）
| 序 | 场景 | 函数(builder.py) | 一句话契约 |

| 1 | first_board_buy 首板买入 | `_buy_first_board` L5202 | 首板封板/回暖买入 |

| 5 | super_exp 超预期加仓 | `_buy_super_exp` L5673 | CORE+LB+BS 顶级超预期 |

并行链 `BuyDecider._price`（decision/__init__.py）补充场景：
- 竞价买入：CORE + AUCTION（竞价价保护涨停价）
- 超预期加仓：CORE+LB+BS（价 x1.02）
- 高开追涨：BS + auction_change_pct>=5%（价 x1.005）
- 低吸买入：CORE + price<=ma5*1.02（价=现价）
- 分笔买入 split_buy：首笔 50%，5 分钟量价确认后再补

## 2. PT 侧实际买入入口（strategies/buysell_core/strategy.py handle_data 派发）
派发顺序：`sell_manager` → `_try_expected_buys` → [daily_max_buy 门] → `try_ma5_buy` → `try_core_buy` → `_try_first_board_buy_1m`
- `_try_expected_buys` L1093 / `place_expected_order` L1613：预期买入（竞价终态→分时确认）；
  mode='board' 打板排队 / mode='chase' 追高；一字封死不排队；300/688 弹性 10% 上限；打板预算 20%
- `try_ma5_buy` L1128：ma5 低吸（CORE+BS+5日首次回踩）—— 本轮已对齐
- `try_core_buy` L1156：v0.18 已实现（CORE + 连板<6 门禁）
- `after_open_probe`(09:31) / `mid_probe`(11:00) / `auction_pre_confirm`(09:25)：探测/读文件，非独立买入
- `firstzt`：仅「首此涨停」采集日志，无首板买入
- `red_gate_enabled` 默认 False（红盘比门未强制）

## 4. 建议落地顺序（按影响/成本）
1. ~~try_core_buy~~（v0.18 已落地：CORE + 连板<6 门禁）
2. **high_open** 并入预期买入链：BS + 开盘涨幅>=5% → 追高现价 x1.005~1.008（有 buy_chase_pct 现成参数）
3. **add_position 加仓**：已持仓核心票二次确认；需先放开 daily_max_buy/cold_secs 对加仓的约束（加仓独立计数）
4. ~~first_board_buy~~（v0.18 已落地：tick 首触「首板确认→打板」，闸门=开盘10分钟内+非一字板+板块内涨幅最高+主动最快拉升）
5. **elastic_arb / agent_buff_opp / resonance**：依赖 L2 逐笔与板块强度，成本最高，暂缓
