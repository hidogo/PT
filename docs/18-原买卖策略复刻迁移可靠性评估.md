- 2026-10-10-1 迁移可行性：axquant 是涨停/打板 + LLM/Agent 门禁 + QMT 桥的重型策略；纯规则逻辑可在 Ptrade 托管内重写，NanoJev/LLM、QMT 交易链路、外部数据源、Dashboard/守护进程、0.2s 亚秒行情不可托管运行。见 docs/16。

## 1. 原买卖策略梳理（AXquant）

### 1.1 买入（TRADING_BUY_SELECTOR_ORDER，行为树多场景）
| 场景 | 触发条件（要点） |
| --- | --- |
| first_board_buy 打首板 | 回暖日(红盘占比≥0.55/情绪温度≥0.50/昨冰点≤0.45/今日增幅≥0.15) + 开盘5min内涨停价成交 + 连续N帧确认 |
| agent_buff_opp / _add_position | LLM/Agent 机会与加仓 BUFF + 现场校验 + NanoJev 概率门禁 |
| add_position 超预期/加仓 | 超预期证据 + 已持仓加仓 |
| super_exp 超预期 | 高开+超预期证据（竞价/涨停价成交） |
| high_open 高开追涨 | 竞价涨幅≥5%（auction 分支硬下限 3%） |
| ma_pullback MA5 低吸 | 回踩 MA5（核心 4 板+ 例外跳过预期闸门） |
| elastic_arb 弹性套利 | 板块一字板≥2 + 1m 大阳 + 涨幅 6~10% + 20cm 弹性 + 事件入池 |
| core_ticket 核心票 | score≥55 + heat≥70 + 连板 LB<6 + leader 1m 上行 |
| board_buy 打板 | 涨停卖单被消化（(卖一-买一)/卖一≤0.30）+ 连续亚秒帧 + 新鲜度≤3s |

买入通用：评分 buy_score_min=45（竞价 50），标签优先级 CORE/LB/BS，静态/动态加减分，攻击加分（9:30-9:35+6 等），动态 VWAP 惩罚，外盘/内盘动态分，每日封顶 N 支、同标的 60s 冷却、行情新鲜度 age 校验。

### 1.2 卖出（SELL_PRIORITY，数字小=先执行）
| 优先级 | 条件 | 触发依赖 |
| --- | --- | --- |
| P0_ACCOUNT_CLEAR | 账户强制清仓 | 资金/风控 |
| P1_GREEN_OPEN | 绿开核卖（竞价/实跌 -5%） | 竞价+开盘 |
| P2_MELT_DOWN | 多标签熔断 | 标签+盘口 |
| P3_STOP_LOSS | 单笔止损 | 止损价 |
| P3B_TRAILING | 盘中最高回落（默认关） | 盘中最高价跟踪 |
| P4_DELAYED_SELL | 不及预期（预期三态） | 见 docs/17 |
| P5/P6_SCORE | 分数清仓 <30 / 减半 30~50 | 实时评分 |
| P7_PROFIT_LOCK | 日内止盈 | 浮盈 |
| （另）炸板卖出 | 涨停跌破 exit_ratio 0.995 + 连续确认 | 涨停/现价 |
| （另）封单衰竭 | 封单量 ≤ 基准×1/3 | 封单强度 |

### 1.3 策略的三大依赖维度
1. 数据：五档/买一卖一（max_ask_bid_ratio）、封单量、板块内一字板数、全市场红盘占比、竞价、1m K、外盘/内盘、涨停阈值、实时快照。
2. 时序：0.2s 亚秒行情、连续 N 帧去抖、行情新鲜度 ≤3s、09:30-09:45 秒级刷新。
3. 外部：LLM（DeepSeek/Kimi/豆包/ARK）BUFF、NanoJev 概率门禁、盘后复盘派生字段。

## 2. 复刻/迁移到 Ptrade 的可靠性评估

评级说明：**高**=数据/时序 Ptrade 原生满足，逻辑等价复刻；**中**=有对等能力但有粒度/节拍/权限缺口，需近似或降级；**低/不可**=缺关键数据或与托管环境冲突，难以原口径复刻。

### 2.1 买入部分
| 场景 | Ptrade 可用对等 | 缺口 | 评级 |
| --- | --- | --- | --- |
| 竞价买入/高开/超预期（auction/high_open/super_exp） | get_trend_data 竞价 + run_daily 盘前 + get_price/get_snapshot | 基本无（口径按券商） | 高 |
| MA5 低吸 ma_pullback | get_history(1d/1m) + MA 计算 | 无 | 高 |
| 核心票 core_ticket | get_fundamentals + get_history（进球热度 heat 需自算） | heat 热度为自研口径，需定义等价项 | 中高 |
| 打首板 first_board_buy | check_limit 涨停 + get_snapshot 现价 + 全市场统计(回暖日) | 涨停价成交确认、连续 N 帧（3s）、全市场统计规模与节拍 | 中 |
| 弹性套利 elastic_arb | 板块个股 get_snapshot + check_limit 统计字板 | 事件入池粒度、1m 攻击性排序调参 | 中 |
| 打板 board_buy(max_ask_bid_ratio) | get_gear_price 五档（需 L2 权限） | (卖一-买一)/卖一 消化比；连续亚秒帧→3s；封单近似 | 低 |
| agent_buff 机会/加仓 | 无 LLM/外网 | 门禁缺失；需规则替代或外置 | 低/不可 |

### 2.2 卖出部分
| 场景 | Ptrade 可用对等 | 缺口 | 评级 |
| --- | --- | --- | --- |
| P0/P3/P5/P6/P7 清仓/止损/分数/止盈 | get_snapshot + order + 实时评分 | 无 | 高 |
| P1 绿开核卖 | get_trend_data/开盘 + -5% 判定 | 无 | 高 |
| P3B 跟踪止盈 | 盘中最高价需持久化 + get_snapshot 轮询 | 无（状态自记） | 中高 |
| P4 不及预期 | 见 docs/17 预期三态 | 封单/LLM 两处 | 中 |
| 炸板卖出 | check_limit 涨停价 ×0.995 + 连续确认 | 连续帧为 3s | 中 |
| 封单衰竭（≤1/3） | 无标准封单接口 | 只能档位量近似 | 低 |

### 2.3 通用/执行可靠性
| 维度 | 评估 |
| --- | --- |
| 交易执行 | order 系列 + on_order_response/on_trade_response 闭环 = 中高；打板能否买进依赖能否以涨停价排队（市价保护/限价+2%笼子钳制） |
| 行情颗粒度 | 0.2s→3s，亚秒去抖/追板失真；09:30-45 秒级刷新无法对齐 |
| 数据保真 | 五档/L2 权限、封单量缺失、外盘内盘权限不确定 |
| 状态连续 | g+pickle 可保证跨日（当日已买 N 支/冷却/炸板后不重买），单进程无并发问题，= 高 |
| 回测可比性 | Ptrade 回测按分钟/日，无法再现打板微观与封单 → 打板类回测失真；低吸/趋势/竞价类相对可信 |
| 外部(LLM/NanoJev/复盘) | 无法托管内运行 → 买卖门禁改变，需规则替代或外置 |

## 3. 结论与建议

**可靠性分层：**
- **可高可靠复刻**：竞价/高开/超预期、MA5 低吸、核心票（heat 需定义等价项）、止损/止盈/绿开核卖/分数清减、预期三态规则部分、状态持久化与订单闭环。→ 建议优先迁移这一子集。
- **中等可靠（需近似/降级/调参）**：打首板、弹性套利、炸板卖出、预期三态（封单缺口）。用 check_limit+get_snapshot+get_gear_price 近似，节拍放宽到 3s。
- **低/不可复刻**：打板(卖买消化比)、封单衰竭/一字板封单、亚秒级微观、LLM/NanoJev/Agent BUFF 门禁。无法在托管内原口径复刻，只能外置（自有服务器决策→Ptrade 执行）或降级为规则近似。

**建议路径：**
1. 在 Ptrade 回测+模拟盘先复刻“高可靠”子集（竞价/低吸/趋势/止损止盈/分数/预期三态），验证收益/回撤是否靠近 axquant 回放。
2. 打板与封单类场景：用 Ptrade 能拿到的涨停+档位+连续 3s 快照做“简化穿透”，并在模拟盘用足够样本重标定阈值；不作为主攻。
3. LLM/BUFF 门禁：默认用规则替代（板块强度、连板、热度、超预期证据）；确有需要再外置 AI 决策主动注入（需券商开外网）。
