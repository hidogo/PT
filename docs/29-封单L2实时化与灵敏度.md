# 29-封单量L2实时化与P4灵敏度测试

> 版本：buyesell_core v0.8f　配套 docs/17（三态口径）、docs/21（L2验证）

## 1. 目标
- 让 P4_exp_one_word 的一字板【封单量】不再是起始一次快照，而是基于第三方 L2 实时刷新；
- 用 L2 买一档【委托笔数】补充“封单是否松动（撤单）”信号，比纯金额更早察觉衰竭。

## 2. 实现（strategy.py v0.8f）
- `_seal_metrics(sec)`：返回 (买一挂单金额, 买一委托笔数)，来自 get_gear_price→bid_grp[1]=[价, 量, 笔数]。仅交易可用（回测不可用）。
- `_exp_one_word(sec)`：
  - 金额比基准：ratio<=seal_fail_ratio→CS；ratio>=seal_exceed_ratio→CX；否则 CM。
  - L2 笔数衰减：seal_bid_enabled 且 bids<bbase*seal_bid_fail_ratio→提前 CS。
  - 每次判定打 `[seal]` 诊断日志（seal/base/ratio/bids/bbase/bid_fail）。
- 新增参数（params.json）：seal_bid_enabled=true、seal_bid_fail_ratio=0.5。

## 3. 灵敏度测试（research/seal/sensitivity_test.py）
- 复刻判定逻辑，对 seal_fail_ratio / seal_exceed_ratio / seal_bid_fail_ratio 扫描，样本含 5 情景。
- 结果要点：
  - 默认阈值（1/3, 1.2, 0.5）下：强封=CM 主，封单炸裂=CS（bar2 起），缓衰=CM，笔数塌=CS，封单增强=CX 主——方向符合直觉。
  - CS/CM/CX 数量在 fail∈[0.2,0.6], exceed∈[1.1,1.5] 内基本稳定（样本情景分离度高），说明默认参数不敏感、稳健。
  - 打开/关闭“委托笔数”判据可改变 3~7 个时点 => 该 L2 特征确实提供了增量信号（尤其在封单金额未跌但笔数塌的“bid_collapse”情景）。
  - 边界：seal_burst bar1 ratio=0.45→CM，fail 抬到 >0.45 会提前到 bar1 判 CS（更早卖出）。

## 4. 用途与局限
- 局限：get_gear_price 仅交易可拿；灵敏度基于合成样本。真实一字板阈值需盘中 `[seal]` 日志校准。
- 校准方法：盘中捕获一字板持仓的 `[seal]` 行，回填 SCEN（research/seal/sensitivity_test.py）重跑，观察 ratio/bids 分布与决策合理性。

## 6. [seal]/[l2] 日志采集器（收盘复盘内）
- 客户端 PTradeQuantApi 无策略日志接口（docs/22）；策略沙盒日志仅在交易 UI 可见。
- 方案：粘贴日志存成 .txt -> research/expectation/log_collector.py 解析入库。
- 用法：
  - `python research/expectation/log_collector.py ingest --file <当日日志.txt> --date 2026-10-16 `
  - `python research/expectation/log_collector.py summary --date 2026-10-16`
- 产出：data/logs/log_<date>.json（l2/seal/may_order/score/expect/error 分桶）+ log_<date>.seal.csv（供阈值回归）。
- 并入收盘复盘：closeout_review.py --logs <当日日志.txt> 会先跑步骤0采集并打摘要，再同步持仓+复盘。
- 典型字段：seal.csv 列 time,sec,seal,base,ratio,bids,bid_fail,state —— 直接喂 docs/29 灵敏度脚本回填 SCEN 做真实阈值回归。

## 7. 一字板竞价终态精确判定（v0.42）
- 口径（用户确认）：**真一字 = 竞价终态 开盘价≥涨停价×0.998 且 卖1=0（total_offerqty==0）且买1有排单量**（涨停股买单全在涨停价，total_bidqty(手)≈封单量）→ 标 `one_word_open`（买入不排队）。
- 卖1>0 → 非真一字（竞价涨停但可参与），不标，打 `[seal] .. playable(非真一字, 可参与)` 日志。
- 开盘后 1 帧内（9:30 起 ≤5s 持续门槛未满）封涨停 → 可参与标的，放行买入；持续封死 5s 后才拦截新买入。
- 落地：`_mark_one_word_open` 判定时回填竞价终态封单基准 `seal_base = total_bidqty×100×涨停价`（金额口径对齐 `_seal_metrics`），`_exp_one_word` 首帧即可判 CX/CS 不再空等 L2 base_init；09:30 首帧（handle_data 首 bar）补标一次（`one_word_marked_open` 按日重置），防 09:25 快照缺失漏标真一字。
- 可识别性（实测）：09:25/09:26 快照已带 open/up 与 total_offerqty/total_bidqty（今日三态合成与 09:31 一字标记均验证字段可用）。
- selftest T95（12 例）覆盖：真一字标 one_word+封单回填 / 卖1>0 不标+playable / 快照缺失→首帧补标 / 真一字 meet 拦截 / 非真一字 meet 放行 / 1帧内封涨停放行、5s 后拦截。
