# 40-情绪冰点→回暖链（红盘比持久化作为情绪转暖依据）

## 1. 规则（用户确认，2026-10-20）
- **T 日冰点**：本地收盘后由涨停池 summary 判定（红盘率/封板率/涨停家数任一低于阈值 → ice=1）。
- **T+1 日盘中**：板块红盘比恢复（≥ 恢复阈值）→ 判定「情绪回暖」；若 T+1 继续冰点
  （实时红盘比 < 冰点阈值）→ 不判回暖，等下一交易日再验证。
- **回暖概率增加**：连续冰点天数 `ice_streak` 越大，恢复阈值越低（`0.55 - streak×0.02`，下限 0.45）
  → 冰点越久，回暖判定越宽松、权重越高。

## 2. 数据契约（本地生成 → 上传 → 云端盘前读入，与 zt_lianban 同链）
文件：`sentiment_<T>.csv`（当日情绪基线）+ `sentiment_latest.csv`（稳定指针，云端首选）。
列：
| 列 | 含义 |
|---|---|
| date | 数据日 T |
| limit_up | 涨停家数（pool_total） |
| break_count | 炸板家数（break_total） |
| seal_rate | 封板率 = 涨停/(涨停+炸板)，小数 0-1 |
| advance_rate | 红盘率/红盘比%（优先 position_review_<T>.jsonl marker extra.emotion_temperature.red_ratio_pct（全市场 tdx ZAF 收盘实时值）；缺失回退 summary.advance_rate_pct（天梯有限样本）并打 WARN） |
| max_board | 最高连板高度 |
| lianban_count | 连板家数 |
| max_board_10d | 近 10 日最高板（含复牌/异动异常点，如 10-16 的 11） |
| max_board_10d_path | 近 10 日最高板路径文本（MM-DD:板数,..，与复盘「近 10 日最高板路径」同源同值） |
| height_suppress | 连板高度压制位（复盘结论「连板高度压制」结构化；云端唯一连板空间闸门消费） |
| ice | 0/1 冰点标记 |
| ice_streak | 连续冰点天数（读上一版 sentiment_latest.csv 累计；冰点+1，否则归 0） |
| 日期守卫(v0.35) | latest 的 date == 当前日期 → 同日重复运行，不重复累计（streak/warm_days 沿用）；latest 更晚 → 视为无前置重新累计，避免未来状态污染 |
| warm_days | 连续回暖/延续天数（v0.30：非冰点日累计；冰点日归 0） |
| phase | ice=冰点 / warm=回暖首日（前一日冰点）/ cont=回暖延续 |
| divergence | 0/1 分歧概率标记（warm_days >= divergence_start，默认 3 → 1） |

生成：`research/expectation/export_sentiment.py`（已并入 run_one_click_after_close 步骤4b / run_one_click_premarket 步骤2b）。
根目录瘦身（v0.35c）：仅保留最近 keep_days（默认3）个 `sentiment_<date>.csv`，更早自动移入 `archive/`（保留审计、不上传）；客户端定时上传仅上传根目录文件、不递归子目录（观察验证 2026-10-20）→ archive/ 确不上传，与 zt_lianban 的 keep_days=3 对齐；云端仅读 `sentiment_latest.csv` + `sentiment_<T-1>.csv`，旧日期文件不影响识别。
冰点判定默认：`advance_rate<40%` 或 `seal_rate<45%` 或 `limit_up<30` → ice=1（--ice-advance/--ice-seal/--ice-limit-up 可调）。

连板高度压制（v1.2，用户确认默认 7 板异动压制）：`_height_path()` 读近 10 个交易日
`limit_up_boards_<date>.json` 的 `summary.max_board`（≤当日）自算，与复盘结论同源（不解析复盘 MD 文本，防格式漂移）：
- 异常尖峰剔除：`max_board>=7` 且次日回落 `>=3`（复牌/异动单点，如 10-16 的 11、10-12 的 10）；
- 新周期 = 最后一个异常尖峰之后（老周期自动隔离，如 10-16 前 8-11 板周期）；
- 压制位 = 新周期内从 T-1 往左第一个「严格高于其后所有值」的值；无 → 周期最高（当前高度即压制位）；
- 交易日文件 <5 个 → `height_suppress=0`（云端放行）并 WARN。
复算验证：10-23/10-26/10-27 压制位均 = 6，与复盘「6 板为当前压制位」一致。

## 3. 云端消费（v0.29，默认关闭）
- `_load_sentiment()`：盘前读 sentiment CSV → g.sentiment（before_trading_start 中加载）。
- `_sentiment_warm(sec)`：未启用/无冰点基线 → None（不参与）；实时全市场红盘比
  （`_market_red_ratio`，全量分片统计）`< sentiment_ice_ratio(0.40)` → 继续冰点 False；否则 `red >= max(0.45, 0.55 - streak×0.02)` → 回暖 True；红盘比缺失 → 保守 False。
- `_buy_red_ok(sec)`：`red_gate_enabled` 开启时要求 板块红盘比≥0.55 且（无冰点基线或已回暖）。
- 参数：`sentiment_enabled=False`（总开关，默认关）、`sentiment_warm_base=0.55`、
  `sentiment_warm_decay=0.02`、`sentiment_warm_min=0.45`、`sentiment_ice_ratio=0.40`。

## 4. 判定示例（10-19 实测）
- 10-19 涨停池 summary：`pool_total=49, break_total=20, advance_rate_pct=37.46, max_board=3, lianban=11`
  → seal_rate=71%，红盘率 37.46% < 40% → **ice=1，streak=1**。
- T+1（10-20）已按全市场红盘比 67.72%（tdx ZAF，涨 3778/跌 1666/平 135）修正落库：红盘比不低于冰点阈值 → **ice=0，streak=0，warm_days=1，phase=warm（回暖首日）**（与 AXquant 复盘“回暖（冰点后修复初期）”一致）。
- 注意：涨停池 summary.advance_rate_pct=37.36 为“天梯有限样本”估算（实为综合晋级率，样本348），非全市场红盘比；故 10-20 不应判冰点（旧数据误标 ice=1 streak=2 已修正）。

## 5. 口径注意
- 红盘比优先取 AXquant position_review marker 的全市场值（tdx ZAF，产出于收盘后复盘；若在复盘产出前跑会回退天梯样本值并 WARN，建议收盘一键在 AXquant 复盘完成后运行）；回退时为天梯有限样本估算（约 355 只），非全市场精确值，冰点阈值按该口径标定。
- v0.41 云端回暖/冰点判定改用**全市场红盘比**（`_market_red_ratio`，全量 get_snapshot 分片统计 涨/(涨+跌)，不含平盘），与本地生成侧口径一致；板块红盘比（`_red_ratio`）仅保留用于买入门 `_buy_red_ok`。
- 默认 `sentiment_enabled=False` + `red_gate_enabled=False`，启用需显式确认（实盘纪律，docs/24 §16）。


## 6. 闭环仓位上限（v0.30，默认关闭）
用户确认（2026-10-20）：情绪因子形成闭环——**连续回暖增加分歧概率；冰点日确认最大总仓位 40%，回暖日确认最大总仓位 80%**。

- **CSV 分类**（export_sentiment.py）：冰点日 → `phase=ice, warm_days=0, divergence=0`；前一日冰点且今日非冰点 →
  `phase=warm, warm_days=1`；否则 → `phase=cont, warm_days=prev+1`；`warm_days >= divergence_start(默认3)` → `divergence=1`。
- **云端消费**（strategy.py v0.30）：
  - `_sentiment_pos_cap(context, sec)`：未启用/无 sentiment → `None`（不限）；冰点基线存在且今日未回暖（实时全市场红盘比 < 恢复阈值）→
    **冰点上限 40%**（红盘比缺失 → 降级冰点 40% 并备注）；已回暖 / 无冰点基线（回暖延续）→ `_warm_cap`；最后叠加 `_emotion_cap` 保守收窄。

## 7. 连板高度压制 → 唯一连板空间闸门（v1.2，默认开启）
用户确认（2026-10-27）：对「唯一连板」作为参与目标做预期参考——距连板高度压制位
`(height_suppress - 当前连板数)/height_suppress >= 15%` 才博弈（P1 口径，默认 15%）。

- **唯一连板判定**（任一命中）：`zt_lianban.unique_high` 权威列 / `_unique_stand` 动态唯一 /
  `_exp_original_theme_leader` 原题材唯一存活龙头。
- **闸门位置**：`_lb_senti_buy_gate`（预期买入 + 首板/回封/弹性统一通道全覆盖）；
  `low` 档（首板/一进二）豁免（天然空间大）；唯一连板空间 < `unq_space_min`（默认 0.15）→
  `(False, 'unq_space_skip(space=xx%,suppress=N)')`，复用 `_lb_gate_seen` 节流打日志；
  唯一高标（空间≈0）自然拦截（对应「唯一高标不应参与」共识）。
- 无压制数据（旧表头/不足 5 日）→ 放行；开关 `unq_space_gate_enabled=False` → 放行。
- 参数：`unq_space_gate_enabled=True`、`unq_space_min=0.15`。
- 示例（suppress=6）：5 板唯一 → 16.7% ≥15% 放行；4 板 → 33.3% 放行；6 板 → 0% 拦截。
  - `_warm_cap(s)`：**回暖上限 80%**，连续回暖 `warm_days >= 3` 起每多 1 天递减 0.10，下限 **50%**（分歧保护，打 `[pos-cap] 分歧保护` 日志）。
  - `_emotion_cap(s)`（v0.41）：复盘 emotion 档位映射——冰点/偏冷→`emotion_cap_ice=0.40`、回暖/发酵→`emotion_cap_warm=0.80`、高潮/过热→`emotion_cap_taper=0.50`（过热分歧保护）；与规则 ice 档冲突时保守取小，缺失（空串）不额外收窄，打 `[pos-cap] emotion=..` 日志。
  - `_buy_pos_ok(context, sec, qty, limit)`：买入后 总持仓市值/总资产 > 上限 → `[pos-cap] ... -> skip`；**两条买入路径统一拦截**
    （place_order 买分支 + place_expected_order，读只/实盘一致可观察）。
- **参数**：`sentiment_pos_cap_enabled=True`（v0.31 已默认启用）、`ice_pos_pct=0.40`、`warm_pos_pct=0.80`、
  `warm_taper_start=3`、`warm_taper_step=0.10`、`warm_taper_min=0.50`、`emotion_cap_ice=0.40`、`emotion_cap_warm=0.80`、`emotion_cap_taper=0.50`。
- **全市场红盘比（v0.41）**：`market_red_enabled=True`、`market_batch=300`（分片批规模）、`market_red_ttl=60.0`（10:00 前快速期 `market_red_ttl_fast=30.0`）、
  `frame_market_limit=2`/`frame_market_limit_fast=4`（独立 market 预算，3s 帧节拍内分配 get_snapshot RPC）；单轮全量（~5500 只）约 19 批，实测 5-15s（券商 RPC 承受力决定），TTL 已参数化供盘中探针校准。
- **日志记录**（v0.31，用户要求）：盘前 `before_trading_start` 打 `[pos-cap] 已启用：冰点上限=0.40 回暖上限=0.80 ... 当前情绪基线：ice=.. warm_days=.. phase=..`；
  盘中每次买入判定打 `[pos-cap] <名>(code) 情绪仓位上限 cap=0.xx (ice=.. warm_days=.. phase=..)`。
- **序列验证（10-19 实测 + 合成）**：10-19 ice(streak=1) → 10-20 warm(warm_days=1) → 10-21 cont(2) → 10-22 cont(3, divergence=1)。
- selftest T67（读新列 / 冰点 40% / 回暖 80% / warm_days 递减 / _buy_pos_ok 超限 skip / 两路径闸门 / v0.31 默认启用）通过；T74（日期守卫：同日重复不虚增 / 跨日冰点+1 / 回暖归 0 / 回补历史不污染）通过；T75（红盘比优先从 position_review / 缺失回退天梯样本并 WARN / 67.72 判回暖而非冰点）通过；T66/T67b（v0.41：全市场红盘比 mock 与缺失降级、emotion 档位六用例——板块红盘比不影响全市场冰点、偏冷收窄 0.40、发酵 0.80、过热 0.50、与规则冰点冲突取保守）通过；T97（v0.44 divergence 显式消费：divergence=1 触发 taper）通过；全量 PASS / 0 FAIL。
