# zt_lianban_latest.csv 盘中消费评估与设计（2026-10-22）

> 状态：v0.55 已实施（2026-10-22）——盘中动态身位/题材强度消费落地，见 strategies/buysell_core/strategy.py 与 T92h 全量回归。

> 数据契约见 docs/33；题材/概念梯队列 v0.54 已由云端策略读入（theme/theme_count/theme_max_board/theme_rank/themes）。
> 本文评估各字段对盘中「身位 / 跟风 / 题材强度」判断的价值，并论证最有效的消费方式。

## 1. 字段价值评估（盘中视角）

### 1.1 身位（高价值字段）
| 字段 | 价值 | 盘中用法 | 局限 |
|---|---|---|---|
| `board_cnt` | 最高 | 身位基线；与 `_today_zt`（今日是否续板）叠加 = 今日动态连板数 | T-1 收盘值，盘中要实时修正 |
| `theme_max_board` | 高 | 题材内最高身位；`board_cnt` 相对它定位「题材龙头 / 中位 / 低位」 | 龙头炸板后失真，需重算 |
| `unique_high` | 高 | 权威唯一高板标签（AXquant 同源），直接放行中位规避 | T-1 状态，盘中龙头炸板/新票晋级后过期 |

### 1.2 跟风（中高价值字段）
| 字段 | 价值 | 盘中用法 | 局限 |
|---|---|---|---|
| `themes`（全量列表） | 高 | 题材成员集的正规来源；交叉题材用全量，不用单一 `theme` | 题材命名以涨停原因标签为准 |
| `theme`（主题材） | 中 | 快速归属/展示 | 单字段会漏掉交叉归属 |
| `follower_count` | 中 | 开盘初始跟风家数 | T-1 静态，盘中需按存活/晋级重算 |

### 1.3 题材强度（中价值字段）
| 字段 | 价值 | 盘中用法 | 局限 |
|---|---|---|---|
| `theme_count` | 中高 | 题材广度先验；盘中叠加「今日新增/炸板」修正 | 静态快照 |
| `theme_rank` | 中 | 主线排序先验，可做排序权重 | 盘中题材轮动快，不能当实时主线 |
| `theme_max_board` | 中高 | 题材高度先验，参与「身位+强度」联合排序 | 同上 |

### 1.4 辅助字段
`limit_up_time / seal_money / reason / is_st / chg_pct` 已有消费：封板质量、封单强度、ST 过滤、涨幅展示。

## 2. 三层消费模型（推荐）

### 2.1 静态锚层（盘前 / 开盘一次）
- 从 CSV 建立 `g.zt_lianban[code]` 记录（v0.54 已含题材列）。
- 按 `themes` 全量列表建题材索引：`theme -> {members, max_board(先验), count(先验), rank}`；
  不用 `theme` 单字段建索引，否则 10-22 的 13/33 只多题材股会漏归。

### 2.2 动态修正层（盘中每帧）
- 今日续板：`board_cnt + 1`（`_today_zt`，已有）。
- 龙头失效：原 `unique_high` 股票炸板 → 该题材最高身位唯一存活者转授动态唯一；
  题材最高板改为存活最高身位。
- 跟风重算：同题材、身位低于当前最高身位且仍在涨停/未炸板的家数。
- 题材强度实时值：`题材当前涨停家数 / 昨日连板晋级家数 / 封单留存均值`。

### 2.3 决策层（消费点）
- `_mid_board_avoid`：中位 = 动态身位 2-5 且非动态唯一龙头且低于题材最高身位；龙头/低位放行。
- `_dyn_unq`：动态唯一龙头 = 题材最高身位唯一存活者（对齐 AXquant 收盘唯一身位重算）。
- `_pool_exp_priority`：排序 = 题材强度分 + 身位分 + 首封时间，避免只按强度追高。
- `_synth_pool_expect`：mid_skip / st_skip 用同一套动态身位口径。

## 3. 最有效消费方式论证

### 3.1 权威列优先，reason 首 token 只作兜底
`board_cnt / unique_high / theme_*` 与 AXquant 复盘同源（`derive_closing_board_status` + `theme.buckets`），
口径一致；`reason` 首 token 分组曾在 10-20 把大业股份/京城股份（同题材并列 3 板）误授唯一、
穿透中位规避。权威列存在时不再用 reason 分组。

### 3.2 身位：动态连板数 + 题材内相对身位
`动态身位 = board_cnt + 今日续板`；题材内定位 = `(theme_max_board 修正值, 动态身位)`，
`unique_high` 作权威龙头标签、`theme_max_board == 动态身位` 且同题材无并列更高时动态授龙头。
中位规避只对「非龙头 + 2-5 板」生效。

### 3.3 跟风：题材成员集按存活重算
用 `themes` 全量列表建成员集，盘中跟风家数 = 同题材、身位低于最高身位、仍封板/未炸板的家数；
`follower_count` 仅作开盘初始值。这比静态列更能反映「板块后排分歧」（炸板即出清）。

### 3.4 题材强度：先验 + 盘中实时修正
开盘用 `theme_count / theme_max_board / theme_rank` 做先验排序；盘中改为
「题材当前涨停家数 + 晋级率 + 封单留存」实时强度。强度只参与排序与观察，
不直接放大追高（板块高潮次日后排无溢价纪律）。

### 3.5 时效性纪律
CSV 是 T-1 收盘快照：09:25 / 09:31 / 盘中每帧必须重算动态层；
高标炸板、一字板、题材轮动都会让静态值失真，禁止把 `theme_count / theme_rank` 当实时主线。

## 4. 量化证据（2026-10-22 实际数据）
- 33 只涨停：首板 24 / 2 板 5 / 3 板 2 / 5 板 2；`unique_high=2`（海洋王、大业股份，高稀缺=龙头信号强）。
- 题材覆盖 32/33；多题材 13 只（约 39%）→ 必须消费 `themes` 全量。
- 14 个题材桶；梯队前二：机器人/自动化 16 家/最高 5 板/rank1；AI/数据要素/算力 10 家/最高 5 板/rank2。
- 权威跟风列：海洋王 follower_count=4、大业股份=13（与 33 只池的宽度匹配）。

## 5. 局限与风险
- 题材来自涨停原因标签（如「羊」字辈），与市场主流概念命名可能有偏差；强度口径应注明来源。
- `unique_high / theme_*` 的权威性只到 T-1 收盘；开盘后必须走动态修正层。
- 动态修正依赖盘中涨停/炸板判定，一字板与 20cm 板阈值要按 `_limit_threshold` 处理。
