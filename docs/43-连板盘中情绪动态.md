# 43 连板盘中情绪动态（v0.65）

## 1. 目的与定位

在消费 `zt_lianban_latest.csv`（T-1 涨停/连板权威池，含 `board_cnt / unique_high / themes / theme_count / theme_max_board / theme_rank`）的基础上，
增加当日盘中情绪动态：**竞价终态（09:25/09:31）-> 盘中确认（09:30-10:00）-> 10:00 冻结（之后降频监控不归零）**，
用于判断赚钱效应停留在中高位，还是兑现并切换到低位首板/新方向首板，作为参与方向、持仓/减仓兑现的指导。

与既有链路的关系：与 P2E（竞价核卖）、P7a/b/c（持仓卖出闭环）不冲突，只读加权/闸门，不改既有信号触发顺序；
P8 兑现指导挂在 P7 之后、P4 之前，命中才卖出，未命中零影响。

## 2. 分档

| 档位 | 判定 | 含义 |
| --- | --- | --- |
| low | T-1 `board_cnt<=1` 或今日新首板（不在 T-1 池） | 首板/一进二低位 |
| mid | T-1 `board_cnt` 2-5 且非权威唯一高标 | 中高位连板 |
| high | T-1 `board_cnt>=6` 或 `unique_high=1` | 高标/唯一身位 |

## 3. 三阶段数据与状态机

### 3.1 竞价终态（09:25/09:31）

`_lb_senti_auction()`：纯读 `g.auction_c`（竞价涨幅，`_overwrite_auction_c` 已按 open/preclose 覆盖）与 spot，零行情 API。
输出 `g.lb_senti.auction`：

- `mid_n / high_n / low_n`：各档家数
- `mid_open_rate`：中高位高开率（竞价涨幅>0）
- `mid_green_rate`：中高位绿开率（竞价涨幅<0）
- `mid_yizi / mid_yizi_rate`：中高位一字家数/占比（`_is_one_word_open`）
- `low_open_rate / low_yizi`：低位高开率/一字家数

### 3.2 盘中确认（09:30-10:00，15s 缓存）

`_lb_senti_mid()`：

- 中高位晋级率 `promo` = 今日续板存活数（`_today_zt`）/ 中高位已触板数（`g.first_zt`）
- 炸板率 `break_rate` = `first_zt.break` 家数 / 触板数
- 封单留存 `seal_retain` = 存活且无 break 事件家数 / 存活家数
- 低位承接 `low_assist` = `_dyn_theme_ferment` 确认题材助攻家数合计；新方向 `new_dir_n` = 临时题材（`THS:*`）确认家数
- 红盘比 `red` = `_market_red_ratio()`（缺失为 None，不编造）
- 样本门槛：中高位触板占比 >= `lb_senti_min_touch_ratio`（0.5）才判 phase，否则 `watch`

状态机（`g.lb_senti.mid.phase`）：

| phase | 条件 | 参与含义 |
| --- | --- | --- |
| high_continue | `promo>=promo_min(0.60)` 且 `break_rate<=break_max(0.20)` | 高位延续，中高位可参与 |
| high_diverg | 晋级/炸板破裂，低位承接未确认 | 高位兑现预警，等低位 |
| rotate_low | 高位破裂 且 `low_assist>=new_dir_min(2)` 或 `new_dir>=2` | 兑现中高位，切低位首板/新方向 |
| ice_wait | `red<red_cold(0.40)` 且低位无承接（或高位强但指数普跌无承接） | 冰点观望，仅低位试错 |
| watch | 样本不足/无中高位池 | 观察不拦截 |

滞回：风险升级（high_continue<watch<high_diverg/rotate_low<ice_wait）需同候选在 `lb_senti_hysteresis_sec`（60s）内二次确认才切换，防单帧抖动；回暖直接切换。

### 3.3 10:00 冻结与降频（不归零）

- `run_daily(..., time='10:00')` 调 `lb_senti_t100_freeze(context)`：强制重算并冻结 `g.lb_senti.t100`（含 auction/mid/phase/hhmm），`_save_state()` 持久化。
- 10:00 后 `_lb_senti_mid` 缓存 15s -> 60s（降频）；参与优先级缩放 `lb_senti_participate_scale`（0.5），冰点再乘 0.5（0.25），**不归零**，保留低位试错通道。

## 4. 消费落点

### 4.1 参与方向加权（只读）

- `_pool_exp_priority(code)` 追加 `_lb_senti_direction_bonus(code) * _lb_senti_participate_scale()`：
  - rotate_low/high_diverg：低位 +1.2、中位 -0.8、高标 -0.6
  - ice_wait：低位 +0.3，其余 0
  - high_continue：中高位 +0.6、低位 +0.2
- `_attempt_expected_buy` 增加 `_lb_senti_buy_gate`：rotate_low/high_diverg/ice_wait 只放行低位（首板/一进二/新方向），中高位新开仓跳过；每 (sec, phase) 只打一次日志。

### 4.2 P8 中高位兑现指导

`_lb_senti_cut_hold(sec)`：phase∈(high_diverg, rotate_low) 且持仓为中位股（`_lb_senti_tier==mid`）且今日未续板（`not _today_zt`）-> 减半兑现（`lb_senti_cut_half_ratio`=0.5）；
高标/低位/续板封住/已兑现（`cut_seen` 去重）不触发。1m `sell_manager` 与 3s `tick_sell_manager` 双链挂在 P7 之后。

## 6. 纪律与风险

- 状态机输出是历史统计倾向，不是确定性信号；P8 只做减半兑现，不抢 P1/P2E/P3/P7 的硬性风控。
- 红盘比缺失时 `red=None`，不做冰点/普跌判定（不编造）；数据源降级不影响 phase 主判定。
- 10:00 后只降频与缩放，不归零：低位首板/新方向仍保留参与通道。
- 切低位/冰点阶段禁止追中高位与板块后排；只聚焦身位股（唯一性苗子）或首板/一进二低位。
