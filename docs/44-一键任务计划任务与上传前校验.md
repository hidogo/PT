## 1. 触发拓扑（谁在什么时点跑什么）

| --- | --- | --- | --- |

红线：**上传必须 09:15 前完成**（原 09:20 文案已全量改为 09:15）。

## 2. 幂等：当日完成标记

- 路径：`data/ptrade_bridge/state/oneclick_after_close_<复盘日>.done`
- 内容：`script / version / trade_date / next_trade_date / generated_at / files`
- 规则：
  - 仅当收盘一键 **rc=0** 才写标记；
  - 计划任务兜底带 `--skip-if-done`，见标记即 rc=0 退出，**不会重复复盘**；
  - 需要强制重跑：删除当日 `.done`（或直接 `python run_one_click_after_close.py --date <复盘日>`，不带该参数不受影响）。
- 非交易日兜底保护：无 `--date` 且当天非交易日时，收盘一键直接 rc=0 跳过（避免节假日空跑覆盖文件）。

## 3. 上传前硬校验（盘前一键 步骤3c）

逐项 PASS/FAIL，任一 FAIL → `rc=6`，清单标注**禁止上传**：

| 文件 | 校验 |
| --- | --- |
| `zt_lianban_latest.csv` | 存在 + 行数>0 + `date`==T-1 |
| `sentiment_latest.csv` | 存在 + 行数>0 + `date`==T-1 |
| `expectation_latest.csv` | 行数>0；存在 `archive/expectation_<T>.csv.meta.json` 时，`row_count` 与 `sha1` 必须**完全一致** |

- `sha1/row_count` 由 `build_expectation_bridge`（from-jsonl → validate）在每次构建时写入 meta，因此：
  - 一致 = 本次构建产物未被覆盖；
  - 不一致 = 上传前被旧文件/半截文件覆盖（历史上出现过 15 行被替换为 5 行），必须重跑收盘一键。
- 空仓 marker 日（`position_expectation_marker`）属正常无预期：预期项打印 `SKIP`，不判 FAIL。

## 4. 计划任务登记

| 任务名 | 时间 | 入口 | 说明 |
| --- | --- | --- | --- |
| `PT-OneClick-AfterClose` | 周一至周五 16:30 | `research/expectation/task_after_close.cmd` | 兜底；带 `--skip-if-done` |
| `PT-OneClick-Premarket` | 周一至周五 09:00 | `research/expectation/task_premarket.cmd` | 验证/补跑 + 上传前硬校验 |

- 运行账号：当前登录用户（`Interactive`，需要 PTrade 客户端已登录时同步持仓才有效）。
- 勾选「错过时间则尽快启动」（`StartWhenAvailable`），关机/休眠后仍补跑。
- 日志：`Logs/oneclick_after_close.log`、`Logs/oneclick_premarket.log`（含每次 start/end 与 rc）。
- 一键登记（需管理员）：`research/expectation/register_oneclick_tasks.ps1`
  - 预览（不注册，普通身份即可）：`powershell -NoProfile -ExecutionPolicy Bypass -File register_oneclick_tasks.ps1 -DryRun`
  - 正式注册：右键 PowerShell → 以管理员身份运行 → `powershell -NoProfile -ExecutionPolicy Bypass -File register_oneclick_tasks.ps1`
  - 脚本内含 `-Force`（重复执行只更新不报错）与入口存在性校验；未提权时直接报 `[FAIL] Administrator required`。
- 查看/手动运行：
  - `Get-ScheduledTask -TaskName 'PT-OneClick-*' | Get-ScheduledTaskInfo`
  - `schtasks /Run /TN "PT-OneClick-Premarket"`

## 5. 失败处置

| 现象 | 处置 |
| --- | --- |
| 16:30 兜底 rc!=0 | 看 `Logs/oneclick_after_close.log`；多为提供方缺失（无当日 ShareData 预期/涨停池）→ 等复盘链完成后重跑 |
| 盘前 rc=6（硬校验） | 预期 CSV 与 meta 不一致 → 删当日 `.done` 后重跑收盘一键，再跑盘前 |
| 盘前 rc=5（供给缺项） | 按 `[供给]` 行提示补跑：收盘一键 / AXquant 复盘后重跑 |
| 09:15 前未上传 | 立即手工上传；盘中 `[pool] expect_buy=0` 即预期链路未生效的自证信号 |
