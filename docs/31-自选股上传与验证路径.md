# 31-自选股上传与验证路径（v0.12 统一股池）

> 版本：buyesell_core v0.12　配合 docs/24（验收）、docs/26（上传识别）

## 1. 自选股文件格式
- 文件名：`selfwatch.csv`（固定名，便于策略重传/同步）。
- 每行一个代码；支持 `.SH/.SZ/.XSHG/.XSHE` 等后缀，也可裸代码，策略自动规范为 `.XSHG/.XSHE/.XBJ`。
- 空行 / `#` 开头注释行自动跳过；含 `code` 表头行跳过。
- 例（data/selfwatch.csv 已有样例）：
  ```
  # 自选股：每行一个代码，可盘中编辑后重传
  600570
  600111.SH
  000002.SZ
  ```

## 2. 上传位置（实时同步）
- **云端研究目录根** `selfwatch.csv`（上传到研究根，随定时/手动上传与当天自选股一并更新）；或
- 云端 **`data/selfwatch.csv`** 目录（与预期 CSV 同套上传路径）。
- 策略机制：`_load_selfwatch()` 在 `before_trading_start` 读一次，且 `handle_data` 每 `selfwatch_sync_interval=8` bar 重读 → **盘中编辑上传即实时并入股池**，无需重启。

## 3. 验证路径（上传后对照）
1. 上传 `selfwatch.csv` 到研究根（或 `data/`）。
2. 看日志：`[pool] selfwatch loaded <路径> -> N`（N=解析到的自选股数）。
3. 看 `[_pool]` … 实际是 `_pool()` 汇总：日志 `[pool] selfwatch=N expect_buy=M pool_static=K`，其中 K = 自选股 ∪ 预期 side=buy 推荐（超预期优先）。
4. 自选股应能：被打分（`score ... <code>`）、进 tick 采集（`_tick_targets` 恒含 `pool_static`）、触发 `[firstzt]`、可被 `[may-order]` 买入。
   - 因此自选股若触板会看到 `[firstzt] <code> ... state=first`。

## 4. 手动添加
- 直接在 `selfwatch.csv` 末尾加一行并重传，不用改代码、不用重启策略；下次同步 bar 即并入。
- 若临时只看（不写文件）：可把想盯的代码临时加进上传的 selfwatch.csv，盘中同步最快。

## 5. 明日盘中核对（复传 v0.12+vol修复 后）
- [ ] `[pool] selfwatch=N` 且 N>0（自选股文件已上传）。
- [ ] `[firstzt]` 的 `vol` 非 0（用 `business_amount`）；`ms` 有值（快照毫秒时间戳，精确触板时刻）。
- [ ] 自选股出现在打分/买入路径（`score ... / [may-order]`）。
- [ ] 预期 side=buy 推荐可被买入（`expect_buy` 计入 `pool_static`），确认超预期(CX)也能买。
- [ ] `expect_buy` 数 = 预期 CSV 中 side=buy 的条目数。

## 7. 读取软件端自选股（客户端本地）
- 客户端「我的自选」存于本机：`D:\gjzq\ptrade\Data\IndividualData.xml`。
  `<IndividualMenu Name="我的自选">` 下每个 `<QuoteCode ProdCode="6位" MarketCode="市场编码"/>`。
  - `MarketCode` 前缀 XSHG/XSHE/XBJ → `.XSHG/.XSHE/.XBJ`。
  - 含 `.MRI` 的是指数/板块（如 000001 上证指数、399001 深成指）→ 跳过；`.ESA` 为 A 股个股 → 保留。
- 工具：`python research/scripts/read_selfwatch.py`（默认读上述 XML，写 `data/selfwatch.csv`；`--xml/--out/--menu/--print` 可选）。
- 约束：策略沙盒在云端**读不到客户端本地 XML**，需先在本机跑工具生成 `selfwatch.csv`，再上传云端研究根（或 `data/`）供 `_load_selfwatch` 实时同步。
- 本机实测：客户端目前「我的自选」含 002343（A 股）+ 2 只指数（已跳过）→ 生成 1 只。

## 8. 一键同步 + 校验（并入复盘）
- 工具：`python research/expectation/sync_selfwatch.py`
