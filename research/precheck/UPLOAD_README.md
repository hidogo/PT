# Ptrade 前期必要测试 —— 上传与运行说明

文件（UTF-8，无 BOM，单个 <50M，逐个上传到「研究」目录）：
- ptrade_precheck_research.py ：**研究** 模块直接运行，做数据/L2 可用性体检（只读）。
- ptrade_precheck_strategy.py ：**托管策略** 形态，做账户/持仓/行情/L2/持久化体检，结果写研究目录（只读）。

## 运行方式
1. 在客户端「量化」里把上述文件**上传到研究目录**（UTF-8；单文件<50M；逐个上传）。
2. 研究脚本：在「研究」打开该文件，点击运行，把 Output 面板结果复制回来。
3. 托管/回测策略：新建策略时用该文件，或用「新建交易(模拟盘)」绑定后运行（L2 需在「交易」模块才有真实数据）。

## 结果位置
- 研究脚本结果 = 研究界面 Output 面板。
- 策略结果 = get_research_path() 下 precheck_result_YYYYMMDD.txt + 策略日志。
  研究根目录一般形如 /home/fly/notebook/（Linux 容器）；云端无法直接访问本地路径。

## 注意事项
- 默认 DO_ORDER=False **只读**，不产生真实委托；如需委托测试请先置 True 并在模拟盘跑。
- 各 get_* 入参在不同券商/版本可能有差异，运行报错时对照终端「帮助/示例」微调签名。
- L2（逐笔委托/成交、档位委托笔数）需要券商开通 Level2 行情权限；未开通返回 None / 委托笔数为 0（见 docs/21）。
- 研究模块与「交易」模块对 L2 的支持不同：以交易模块结果为准。

## 测试通过判定
- 行情：get_history/get_price/get_snapshot 返回有效数据。
- 证券/板块/财务：get_stock_name/get_stock_info/get_stock_blocks/get_fundamentals 有返回。
- L2：get_gear_price 五档、get_individual_* 非 None（交易时段 + 已开通 L2）。
- 持久化：persistence(pickle) OK、precheck_result 文件生成。
- 账户：get_positions / context.portfolio.available_cash 有值。

## 为什么「回测卡片」看不到上传的文件（重要）
Ptrade 里**「研究」目录与「策略/回测」是两套独立的东西**：
- 上传到「研究」目录的 .py = 研究脚本/资料，**不会自动出现在回测卡片里**。
- 回测卡片只能选择**通过「策略」模块「新建策略」创建过的策略**（回测界面的对象=策略列表，见前端弹层）。
所以想用本测试文件做「回测」，必须先在建策略时把它“变成策略”：
1. 进入「策略」模块 → 点「新建策略」→ 业务类型选「普通股票」、命名（如 ptrade_precheck）。
2. 在策略编辑器里把 `ptrade_precheck_strategy.py` 的内容全部粘贴进去（或看编辑器是否提供「从研究目录导入」）。
3. 保存 → 该策略才会出现在策略列表，回测卡片里才可勾选并点「运行回测」。

补充约定（写到 results 时注意）：
- 回测是历史回放（每日/分钟跑一遍），只读行情，L2 接口在回测里会报错/返 None —— 属正常，L2 体检要用「交易」模块。
- 最快要“跑起来”：研究模块或策略里直接运行的是**直接可跑脚本**；回测卡片只是“历史验证”通道，不是首轮冒烟测试的必经路径。
